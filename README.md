# fga-data

This is where the FGA Data lives to be downloaded where the https://github.com/ArthurKun21/fga-data-parser/ converts raw [Fate/Grand Order](https://www.fate-go.jp) data from the
Atlas Academy API into a format that can be used by
[FGA (Fate/Grand Automata) Preview](https://github.com/ArthurKun21/fga-preview-build).
